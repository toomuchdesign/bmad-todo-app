Color tokens

All colors are accessed via semantic tokens (--s-*). Never use primitives (--p-*) directly in components — only in the token definitions themselves. This keeps the palette swappable from a single source.

Spacing scale

Base unit is 2px. All layout distances are multiples of this unit. Use these token names, never raw pixel values.

--s-space-0-5
2px · micro: icon padding, tiny gaps
--s-space-1
4px · label↔input gap
--s-space-1-5
6px · ghost button padding-y, textarea gap
--s-space-2
8px · inline element gaps, meta margin-top

10px · input/button padding-y
--s-space-3
12px · input padding-x, item column gap
--s-space-4

UI Atoms

Layout

AppShell & AppHeader

The app shell is a centered column, max-width 640px, with inline borders. All components use margin: 0 --s-space-4 for horizontal alignment (never padding on the root). The only exception is the GlobalErrorBanner which is truly full-width.
